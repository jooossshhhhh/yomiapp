## Yomi v1.0.0-beta

Initial public beta release of Yomi — a fast, private, offline-first Android PDF reader and document workspace built with Kotlin and Jetpack Compose.

### What's New
- **Multi-Mode PDF Reader**: Read smoothly in Continuous Scroll, Single-Page, or 2-Page Book Spread views with an interactive Page Thumbnails grid, zoom presets, 90-degree rotation, fullscreen mode, and full-text search.
- **Annotations & Export**: Draw freehand ink, highlight passages, add sticky notes, and save or export flattened annotated PDFs.
- **Offline-First Document Conversion**: Convert Word (DOCX, DOC), Excel (XLSX, XLS), PowerPoint (PPTX, PPT), Text (TXT), and images to PDF directly on-device with zero cloud credits required.
- **Resilient Cloud Fallback Proxy**: Automatic online fallback conversion handled securely through a dedicated proxy service when an offline conversion encounters complex layouts.
- **Yomi Quick Suite**: Built-in tools to Merge PDFs, Split specific page ranges, and combine multiple Images into a single PDF.
- **Read-Safe Google Drive Workspace**: Connect your Google account and link Drive folders to browse and convert cloud documents locally without altering files in your Drive, or unlink a connected folder anytime without deleting your local Yomi copies.
- **Smart Organization & Recents**: Organize documents into custom folders, bookmark Favorites, auto-scan local storage, and resume right from your last read page.
- **Adaptive Reading Themes**: Switch between Light, Dark, and Sepia themes with customizable accent styles.
- **Built-In Update Checker**: Check for new app releases and view release notes directly inside Profile & Settings under About Yomi.

### Fixes & Improvements
- **Custom Launcher Icon Compatibility**: Updated adaptive and monochrome launcher icons so the Yomi app logo displays reliably across both stock Android and third-party home launchers.
- **Signed Release Build Optimization**: Configured R8 shrinking, WorkManager/Room keep rules, and release APK signing (19.24 MB) for reliable startup, faster performance, and smaller download size.
- **UI & Stability Refinements**: Improved About Yomi layout, advisor credits presentation, and overall app stability.

### Release Details
- **Version**: v1.0.0-beta (Build 1)
- **Minimum Android Version**: Android 8.0 (API 26) or higher
- **Package ID**: com.yomi.app
- **APK File**: yomi-v1.0.0-beta-release.apk (19.24 MB)
- **Upgrade Note**: If you previously installed a Debug build, uninstall it before installing this signed Release APK.
