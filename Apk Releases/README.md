# Apk Releases

This folder stores signed Yomi release `.apk` builds organized by version (for example, `yomi-v1.0.0-beta-release.apk`).

> **Note:** `.apk` binary files are excluded from Git tracking via `.gitignore` (`*.apk`) to keep the repository lightweight. Upload each versioned APK from this folder directly to the corresponding tag on [GitHub Releases](https://github.com/jooossshhhhh/yomiapp/releases).

- `yomi-v1.0.5-release.apk` — Feature & conversion fidelity release (`v1.0.5`, Build 2)
